AI Engineering Laboratory

A platform where an AI agent will one day design, model, simulate, analyse, test and improve engineering systems. Stages 1–11 are live: the dashboard, six laboratories, a real 3D workspace, a materials database and a component library, plus accounts and per-user projects, real analytical solvers in every lab, and an AI Engineering Assistant that answers in plain language by running those solvers. The backend runs locally — start it with cd backend && python3 app.py to sign in and save.

What Stage 1 does — and does not do

✓ Works now

Navigation, dashboard, six lab pages, real 3D modelling workspace (parametric geometry, CSG booleans, assemblies, STL/OBJ/GLB export), a Simulation Workspace (Rapier rigid-body dynamics + analytical beam/thermal/fluid solvers), a Mechanical Laboratory (gear trains, crank-slider, 11 mechanical solvers, bill of materials), an Electrical Laboratory (real MNA circuit simulator, schematic editor, motors and batteries), a Structural Laboratory (real direct-stiffness solver, buckling and modal analysis, IS 875 / IS 1893 calculators), an Aerospace Laboratory (thin-airfoil + lifting-line performance, Tsiolkovsky delta-v, Barrowman stability, trajectories), a Robotics Laboratory (DH kinematics, IK, PID control, collision checks, mobile robots), and an AI Engineering Assistant (plain-language questions answered by the real solvers, with provenance labels and approval-gated project changes), Material Library with 38 materials across 10 categories (search, favorites, comparison, recommender), component library, project creation and JSON export.

✕ Not yet

Plate/shell/solid FEA, CFD, and a hosted production backend — the backend runs on your own machine for now, so the live site is a static frontend until you start it locally. No code-compliance checking (IS 800 / IS 456 / AISC / Eurocodes) and nothing here is validated for manufacturing or construction. See STATUS.md.

Hosting: GitHub Pages (qogtrix.github.io). Custom domain qogtrix.is-a.dev goes live after is-a.dev PR #61755 is merged — see Run & Deploy.
